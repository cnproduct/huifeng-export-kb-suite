## 🚀 Quick Start Guide

### 1. Run Complete Site Link & Template Variable Health Check
```bash
python3 scripts/link_ast_scanner.py --dir /path/to/website
```

### 2. Check and Optimize Keyword Density (Prevent Keyword Stuffing)
```bash
python3 scripts/keyword_density_optimizer.py --file /path/to/index.html --word "stone" --target-density 0.02
```

### 3. Generate Complete AI Discovery Suite
```bash
python3 scripts/ai_discovery_generator.py --kb-json /path/to/enterprise_kb.json --out-dir /path/to/website
```

### 4. Compile Comprehensive LLMS.txt (5,000+ Words)
```bash
python3 scripts/llms_compiler.py --catalog /path/to/catalog.json --out /path/to/website/llms.txt
```

### 5. Run Live GEO Production Audit
```bash
python3 scripts/geo_audit_runner.py --url https://yourdomain.com
```
