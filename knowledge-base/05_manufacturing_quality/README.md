# 05 制造硬实力与品质控制 (Manufacturing & Quality)

## 制造硬件指标
- **生产线数量**: 35 条全伺服自动化高速组装产线
- **最高运行车速**: 600 片/分钟（单线日产达 40–50 万片）
- **厂房面积**: 11,800 平方米 GMP 十万级净化车间
- **制造工序**: 118 道标准化智能制造工序
- **在线质检节点**: 398 个自动化视觉与机械检测点

## 权威质检合作：中科惠聚 CMA 实验室
- **机构全称**: 中科惠聚 (福建) 检测技术有限公司
- **CMA 资质认证**: 2019 年 8 月获福建省市场监督管理局颁发的资质认定证书（CMA-FJ-2019-HUICMA）
- **权威地位**: 全省首家取得新版卫生巾（护垫）标准全项检测资质的第三方权威检测机构
- **核心检测指标**:
  - **吸收倍率与吸收速度**: 依据 ISO 11948-1 标准检测，生理盐水吸收率达 60g/g 以上
  - **回渗量测试**: 5kg 标准砝码加压测试，回渗量严格控制在 < 0.2g
  - **微生物指标**: 细菌菌落总数 < 20 CFU/g，真菌菌落总数未检出，致病菌（金黄色葡萄球菌、铜绿假单胞菌、溶血性链球菌）一律不得检出
  - **荧光迁移测试**: 紫外光下可迁移性荧光物质检测为零
