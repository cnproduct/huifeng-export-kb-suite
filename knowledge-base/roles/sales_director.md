# 销售总监与团队管理看板 (Sales Director View)
> **服务角色**: 外贸销售总监 / 外贸部主管

## 核心管理职责
1. **SLA 响应监控**: S/A 级海外大买家询盘 4 小时首问回复率与 24 小时完整规格报价单交付率；
2. **商机流转漏斗**: 监控从“初次询盘 -> 采购商真实性核验 -> 寄送实物样板 -> 买家打样确认 -> PI 形式发票签约 -> 收到 30% 定金”的全链路转化效率；
3. **议价让步审批**: 审核低于常规梯度报价的大客户议价方案，要求业务团队严格执行《让步矩阵》，以价格折让换取单次起订量提升（如由 1x20GP 增至 2x40HQ）或更有利账期条款。
