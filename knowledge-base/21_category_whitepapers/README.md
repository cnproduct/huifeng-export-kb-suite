# 21 品类专业白皮书与工程规范库 (Category Engineering Whitepapers)

本目录收录了泉州市惠丰妇幼用品有限公司 (Quanzhou Huifeng Sanitary Articles Co., Ltd.) 旗下 **12 大核心卫生用品品类** 的完整出口工程白皮书（**中英双语 / 西班牙语双版本**）。
