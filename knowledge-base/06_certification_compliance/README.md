# 06 认证与合规档案 (Certifications & Compliance)

## 已核验企业与产品资质台账
1. **ISO 9001:2015 质量管理体系**: 证书编号 CN21/10982-HF，覆盖全系列卫生巾与吸收性卫生用品研发与生产。
2. **ISO 13485:2016 医疗器械质量管理体系**: 证书编号 Q5 089234 0018，覆盖医用一次性看护垫与成人失禁用品。
3. **欧盟 CE MDR 2017/745 Class I**: 欧盟合规声明，医用看护垫具备合法欧盟市场自由流通资格。
4. **美国 FDA 境外生产企业注册**: FEI 3012984561，覆盖个人吸收卫生用品与失禁用品。
5. **CMA 实验室检验合格报告**: 中科惠聚出具的定期监督型检报告，指标全面优于 GB/T 8939 及行业标准。
6. **OEKO-TEX Standard 100 Class 1**: 婴儿皮肤接触级无纺布安全认证，不含有害化学物质。
7. **FSC 森林产销监管链认证 (FSC-C149802)**: 保证所用纯木浆均来自可持续合规林场。
8. **Dermatest 五星临床测试**: 皮肤无刺激 0.00 指数，敏感肌适用。
