# 07 商务政策与履约交付 (Commercial Delivery)

## 商务交付条款
- **出运港口**: 厦门港（Xiamen Port，主出运枢纽）/ 泉州港（Quanzhou Port）
- **结算方式**: 30% T/T 订金，70% 凭提单副本见票即付；或即期不可撤销信用证（L/C at sight）
- **标准起订量 (MOQ)**:
  - 卫生巾 / 护垫 / 经期裤: 单规格 100,000 片
  - 婴儿纸尿裤 / 拉拉裤: 1 个 40HQ 高柜（约 360,000 片，可拼 2–3 个尺码）
  - 成人纸尿裤 / 拉拉裤: 1 个 40HQ 高柜（约 75,000–85,000 片）
  - 医用看护垫: 1 个 20GP 小柜（约 60,000 片 60x90cm）
  - 婴儿湿巾: 30,000 包（80 抽带盖）
- **生产交期**: 首单定制版面 20–25 天（含版辊雕刻与胶袋印刷），复购翻单 15 天内极速交付
- **集装箱装柜优化 (40HQ High Cube)**:
  - 卫生巾标准箱: 约 1,600–1,800 箱（约 60–86 万片）
  - 纸尿裤高压压缩大包: 容积利用率达 95% 以上，显著摊薄单位海运费
