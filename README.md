## 🌟 核心理念：企业真实事实 × 100/100 GEO 搜索引擎优化

本项目由两大互补内核一体化融合而成：
1. **企业大脑事实内核 (`knowledge-base/` & `sites-matrix/`)**：
   - 21 个标准出口知识模块、全品类 PIM 主数据（卫生巾、雪莲养护贴、经期裤、婴童纸尿裤、婴儿拉拉裤、竹纤维环保纸尿裤、成人纸尿裤、成人拉拉裤、医用看护垫、产妇垫、婴儿湿巾、医用消毒湿巾、宠物尿垫）。
   - 真实制造硬实力：11,800 ㎡ 现代化无尘车间、294 名员工（177 名产线操作工、21 名专业质检人员）、35 条全伺服高速自动化产线（最高 600 片/分钟）、118 道工序与 398 个质检节点。
   - 权威资质与检测：中科惠聚 (福建) 检测技术有限公司 CMA 实验室资质、ISO 9001:2015、ISO 13485:2016 医疗器械体系认证、欧盟 CE MDR 2017/745 Class I 符合性声明、美国 FDA 工厂登记 (FEI 3012984561)、OEKO-TEX Standard 100 Class 1 及 Dermatest 0.00 致敏五星认证。
   - 6 大岗位专属实战手册（管理层、销售总监、资深业务、新业务、海外营销、运营质检）。
2. **全网 AI 发现与 GEO 优化引擎 (`geo-optimizer/` & `generators/`)**：
   - 原生集成 `renwork-seo-geo-optimizer` 全套能力，直接为 20 个独立站输出 27 家 AI 爬虫矩阵 `robots.txt`、5,000+ 字全量深度 `llms.txt`、AI 机器发现四件套（`/.well-known/ai.txt`, `/ai/summary.json`, `/ai/service.json`, `/ai/faq.json`）、出版级多实体链接 Schema.org `@graph`、WebMCP 智能体表单协议以及词频防堆砌控制。

│   ├── 06_certification_compliance # ISO 9001/13485、CE MDR、FDA登记、OEKO-TEX、Dermatest
│   ├── 07_commercial_delivery/ # 阶梯报价、MOQ门槛、模具返还政策、40HQ集装箱测算

│   ├── sites.json              # 20 站完整配置
│   └── sites/                  # 20 份独立站 Markdown 详细战略简报

│   ├── claim-guard.mjs         # 真实性与虚假宣传审计防线 (HF-EVD 编码)
│   ├── geo-bridge.mjs          # 20 站全量 GEO 资产批量编译器
│   ├── site-content-generator.mjs # 35 页模板派生生成器
│   ├── sitemap-generator.mjs   # 动态 XML/HTML 站点地图生成器
│   └── llms-generator.mjs      # llmstxt.org 规范编译器
├── portal/                     # 交互式出口知识库前端门户 (HTML/CSS/JS)
├── mcp/                        # Model Context Protocol 智能体服务接口
└── scripts/                    # 严苛的自动化测试套件

## 🚀 极速起步与常用指令

```bash
# 1. 运行整套知识库与 GEO 规范全域审计 (100% 必须通过)
npm run verify

# 2. 运行 20 站内容生成冒烟测试
npm test

# 3. 运行证据台账与合规闸门审计
npm run test:evidence

# 4. 批量生成 20 个独立站的 100/100 GEO 资产包
npm run geo:build

# 5. 启动本地交互式知识库门户
npm run start:portal

# 6. 启动 MCP 智能体协议服务
npm run start:mcp
```
